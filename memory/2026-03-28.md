- `paper-manager` と `gmail-knowledge` を GitHub に作成・push済み。Vercel へデプロイし、URLは `paper-manager-three.vercel.app` / `gmail-knowledge.vercel.app`。
- `paper-manager` は Vercel 上で複数の 500 を解消した。主な原因は (1) PyMuPDF / `uvicorn[standard]` などのネイティブ依存、(2) 重い import のトップレベル実行、(3) Starlette/Jinja2 の `TemplateResponse` 新シグネチャ不一致。現在トップページはブラウザで正常表示を確認済み。
- `paper-manager` は機能がかなり進んだ: PDF登録、一覧/検索、詳細、メモ、関連表示、手動修正、ソート/フィルタ、CSV/JSONエクスポート、API検索。`gmail-knowledge` も同等水準まで整備。
- Notion Public OAuth は仕様上存在するが、Notion の現行UI導線が分かりづらく、途中で internal / public の切り分けで混線した。最終的に Public integration 自体は発見でき、Redirect URI `https://paper-manager-three.vercel.app/auth/callback` を使う本命ルートが見えた。
- ただし onboarding を止めないため、`paper-manager` は Internal Integration トークン入力方式も実装済み。トークン検証後にDB一覧へ進み、DBが無い場合は「📚 DBを自動作成してはじめる」導線を追加。
- Notion 側では internal integration `paper-manager` が既に作成されていることを確認。DB自動作成まわりは権限/親ページ接続問題で詰まったため、フォールバックとして接続済みページ配下にDBを作る実装が追加された。
- 運用上の教訓: 機密情報（Vercel token、Notion token/client secret）がスレに貼られた。漏洩扱いで再発行を促す必要がある。今後は「このスレに貼らない」を明確に先出しする。
