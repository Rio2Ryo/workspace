## Claude Code 接続問題（3/12-3/17）
- **momo（Windows Surface2）での Claude Code 実行**：SSH 経由では OAuth 認証が通らない（Windows Credential Manager がリモートセッションからアクセス不可）
- **試した方法（全て失敗）**：SSH 直接実行、タスクスケジューラ、PsExec、WSL2 インストール（管理者権限不足）
- **突破方法**：ブラウザ操作（browser ツール）で claude.ai/code セッションに直接入力することで成功
- **重要**：API キーは課金されるため使用禁止（Yakon さんの指示）。OAuth サブスク認証のみ使用すること

## ブラウザ経由の Claude Code 操作
- claude.ai にログイン済みの状態で、browser ツールの act/type/press で入力可能
- セッション URL: `https://claude.ai/code/session_XXXXX` の形式
- 入力欄は `[contenteditable='true']` セレクタで取得可能
- Enter キーで送信
