## 技術的課題と解決

### PencilKit API の変更（iOS 26）
- `PKDrawing.draw(in:from:scale:)` → `draw(in:from:frame:)`
- `PKInkingTool.InkType` → `PKInkingTool.Ink`
- `ballpointPen` は `pen` に統合
- 簡易実装で対応

### SwiftData API の変更
- `ModelContainer(for:inMemory:)` → `ModelContainer(for:configurations:)`
- `@Preview` の `previewContext` は不要に

### Xcode プロジェクトファイル
- 手動編集は破損リスクあり
- Git 復元 + スクリプトで安全に追加
