## Gohanai OpenClaw gateway / openai-codex auth failure
- 何が起きたか: Discord上で Gohanai gateway の `openai-codex` model login failure が発生。ログでは `refresh_token_reused` により `openai-codex/gpt-5.5` と `gpt-5.4` が失敗し、Anthropic fallback も billing で失敗していた。
- なぜ起きたか: Gohanai側の `~/.openclaw/agents/main/agent/auth-profiles.json` に入っていた `openai-codex:default` OAuth が `2026-05-27T23:01:13Z` で期限切れ、かつ refresh token が再利用済みになっていた。
- 対応: ローカル側の有効な `openai-codex` OAuth状態（期限 `2026-06-09T10:43:05Z`）を Gohanai の `auth-profiles.json` / `auth-state.json` に同期。同期前に Gohanai の既存ファイルを `~/.openclaw/agents/main/agent/backups/` に退避。`systemctl --user restart openclaw-gateway.service` で gateway を再起動。
- 確認: `openclaw models auth list` で Gohanai側の `openai-codex:default` 有効期限更新を確認。gatewayログで `agent model: openai-codex/gpt-5.5` と `gateway ready` を確認し、再起動後の `token refresh failed` は出ていない。
- 次回どう防ぐか: gateway系エラーで `Model login failed` が出たら、まず対象ホストで `openclaw models auth list` と `journalctl --user -u openclaw-gateway.service` を確認する。`refresh_token_reused` の場合は同一アカウントの有効な auth state を同期するか、`openclaw models auth login --provider openai-codex` で再ログインし、最後に gateway service を再起動する。
