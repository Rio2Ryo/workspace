## tmux Web View — shiro feed非表示
1. 何が起きたか: Yakonさんから `#tmux-web-view` で「Shiroのセッションが切れているため表示されない」と報告。Vercel `/api/sessions` では `shiro` hostのみ `Feed fetch failed`、panai/gohanai/soraは正常。
2. なぜ起きたか: Mac mini側のtmuxサーバーが停止しており、さらに `shiro` の一時Cloudflare Tunnelも落ちていた。`trycloudflare.com` URLはプロセス停止後に同じURLへ復帰できない。
3. 次回どう防ぐか: tmux Web Viewの監視対象は、tmux本体、local feed、公開トンネル、Vercel envの4点をセットで確認する。恒久運用は一時URLではなくnamed tunnelまたは固定到達手段にする。
4. ルール反映: `shiro` hostが非表示の時は、先に `tmux ls`、local feed `/sessions`、本番 `/api/sessions` の順で切り分ける。
