## Sora VPS — Hermes gateway self-restart outage
1. 何が起きたか: 2026-05-25 10:11 JST、Sora-VPS2 が `Gateway shutting down — Your current task will be interrupted.` を出して停止。`sora-hermes` tmux session が消え、Discord応答が途切れた。
2. なぜ起きたか: Soraが `hermes gateway restart` をHermes自身のterminal tool内で実行し、稼働中のHermes gatewayへSIGTERMを送った。親がtmux起動コマンドだけだったため自動復帰せず、停止通知だけが出た。サーバーOOMやホスト再起動ではなかった。
3. 対応: `ssh sora` のaliasを追加し、`root@160.251.199.55` に `~/.ssh/id_ed25519_vps` で接続可能にした。`tmux new-session -d -s sora-hermes ... hermes gateway run --replace --accept-hooks -v` でSora Hermesを復旧し、`Sora-VPS2#5856` のDiscord接続を確認した。
4. 次回どう防ぐか: Hermes自身の中から `hermes gateway restart` を実行しない。再起動が必要な場合はSSH外部からtmux/systemdで停止・起動する。`sora-hermes` が落ちたらまず `ssh sora 'tmux ls; tail -n 120 /root/.hermes/logs/sora-hermes-gateway.log'` を確認する。
5. ルール反映: Sora VPSのSSH先は `sora` / `sora-vps`。Sora関連のtmux sessionは `sora-hermes`, `sora-codex`, `sora-claude`, `sora-goose`, `sora-openclaw`, `sora-grok`。

## Sora VPS — Gateway shutdown exact trigger
1. 何が起きたか: Yakonさんから `Gateway shutting down — Your current task will be interrupted.` の理由を再調査依頼。Hermes logに `Received SIGTERM as a planned gateway stop` と、active chat `discord:1472597788343668850` への shutdown notification 送信が記録されていた。
2. なぜ起きたか: 既存Hermes gateway稼働中に別プロセスで `hermes gateway run --replace --accept-hooks -v` が起動し、`--replace` の仕様で既存gatewayへSIGTERMを送った。親プロセスは `bash -c ... hermes gateway run --replace ... | tee ...`。OOM/ホスト再起動/Discord 401ではない。
3. 対応: `sora-hermes` tmux sessionを外部SSHから再作成し、今回は `--replace` なしの `hermes gateway run --accept-hooks -v` で起動。`Sora-VPS2#5856` としてDiscord接続、channel directory構築、gateway runningを確認した。
4. 次回どう防ぐか: 既存gateway生存確認なしに `--replace` 付き起動を使わない。復旧時は `tmux has-session -t sora-hermes`、`pgrep -af "hermes gateway run"`、`tail /root/.hermes/logs/sora-hermes-gateway.log` を確認してから、必要な場合だけ外部SSHで再起動する。
5. 例外時に確認する条件: `--replace` を使う必要がある場合、またはsystemd化/常駐方式変更が本番運用に影響する場合はYakonさんへ確認する。
