# アグリ・ジパング HP 作成 — 長期記憶

## 案件概要
- **クライアント**: 農事組合法人アグリ・ジパング
- **目的**: 信頼感のあるコーポレート LP を最短で公開
- **主ターゲット**: 自治体 / 企業（最優先）、投資家/提携先（次点）
- **主訴求**: 営農型太陽光発電 + CO2 削減ソリューション（2 本柱）

---

## 設計方針（確定）

### 構成
- **6 セクション**: Hero / 概要 / 事業内容 / 実績・取り組み / 会社概要 / お問い合わせ
- **事業構成**: 2 主役（太陽光/CO2）+ 1 補足（農業・資材・バイオマス）
- **MVT 扱い**: 連携プロジェクトとして軽め（初版は埋め込み）

### Hero 方針
- **画像**: 静止画優先（動画は素材次第）
- **数値優先順位**: 1.CO2 削減量 2.発電規模 3.設立 2015 年
- **伝えること**: 事業内容/ターゲット/信頼材料

### 実績セクション
- **KPI 優先順位**: 1.CO2 削減量 2.発電規模 3.対応エリア 4.設立年
- **表示ルール**: カード形式/大きな数値/出典・年度・算出根拠明記
- **数値が弱い場合**: 設立年/所在地/事業領域を優先

### 会社概要
- **信頼性セクションとして扱う**
- **前面情報**: 設立 2015 年/資本金 1,000 万円/代表/役員 6 名/所在地/連絡先

### 問い合わせ
- **ゴール**: 商談/導入/提携相談
- **配置**: ヘッダー/Hero/実績下/フッター（4 カ所）
- **CTA コピー**: 「導入・提携を相談する」/「事業について相談する」/「ご相談はこちら」
- **フォーム**: 7 項目（会社名/氏名/メール/電話任意/区分/興味事業/種別/内容）+ 5 機能（入力/バリデーション/完了画面/自動返信/管理者通知）

### 写真方針
- **優先順位**: 1.太陽光設備×農地 2.会社外観 3.代表写真 4.現場写真（森林/海藻/飼料）
- **原則**: 実写優先（ストックより信頼性）
- **素材不足**: 静止画少なめ + タイポ中心

### CMS 方針
- **初版**: LP 先行（静的）
- **将来**: 更新頻度高ければ Sanity 導入
- **後付け可能**: News/実績追加/MVT 詳細/資料 DL

### 技術方針
- **第一候補**: Next.js 15 + Tailwind CSS + Vercel
- **Sanity**: 更新運用次第

### SEO 方針
- **初版戦略**: 検索流入より「見た時に信用される」LP
- **必須項目**: title / meta description / OGP / 見出し構造
- **本格運用**: 実績/事例/News 増加後
