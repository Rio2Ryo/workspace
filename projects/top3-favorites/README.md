# top3-favorites-app

トップ3や好きなものを、**1つの大きな入力欄**から素早く記録するMVPアプリです。

## セットアップ

```bash
npm install
npm run dev
```

- ブラウザで表示された `http://localhost:5173` を開く

## 入力方式（MVP）

1つの入力欄に次の形式で入力して追加します。

```txt
タグ群 / 順位 / 名前 / メモ
```

例:

```txt
松戸 ラーメン つけ麺 / 1位 / とみ田 / 濃厚つけ麺が好き
柏の葉キャンパス カフェラテ / 1位 / Solito MAGO / ラテアートがきれい
```

- タグ群: 空白区切りで複数指定（`#`付きでも可）
- 順位: `1位`, `2位`, `3位` など（数字1〜3を抽出）
- 名前: 店名や場所名
- メモ: 任意（省略可）

## 機能

- かんたん入力（簡易パース）
- localStorage への保存（DB不要）
- タグ・店名・メモの検索
- タグチップからの絞り込み
- テーマ（タグセット）ごとのTop3表示
- 編集・削除
- Google Maps検索リンク
  - `https://www.google.com/maps/search/?api=1&query=...`

## 補足

- 厳密な重複制約や「同テーマで必ず1〜3位のみ」等はMVPでは未実装
- まずは登録・編集・削除のしやすさを優先
