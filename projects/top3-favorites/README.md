# top3-favorites-app

「このカフェラテうめぇ」から、その場で **カフェラテTop3の何位に入るか** を記録するMVPアプリです。

## セットアップ

```bash
pnpm install
pnpm dev
```

## UX方針

以前の大きな自然文入力は、登録時に「何をどう入れればいいか」が分かりづらかったため廃止寄りに変更しました。

新しい導線:

1. 何のTop3かを入れる（例: カフェラテ）
2. 必要ならエリアを入れる（例: 柏の葉）
3. 同じテーマの既存1〜3位を見る（エリア違いも含めて確認）
4. 店舗名を入れる
5. 1位/2位/3位のボタンで順位を決める
6. 追加後の並びをプレビューして登録

## 機能

- テーマ別Top3管理（例: カフェラテ）
- 入力中テーマの現在Top3表示
- 追加後の順位プレビュー
- 同一テーマ順位の自動繰り下げ（3位まで保持）
- 店舗名・タグ・メモ検索
- タグチップ絞り込み
- 編集・削除
- Google Maps検索リンク
- JSONエクスポート/インポート
- localStorage保存（外部APIなし）

## 検証

```bash
pnpm build
```
