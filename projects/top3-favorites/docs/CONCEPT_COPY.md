# top3-favorites-app コンセプト / コピー整理

## コンセプト

top3-favorites-app は、好きなものを「Top3」という小さな単位で記録する偏愛ログです。

日記ほど重くなく、ブックマークほど無機質でもない。  
「松戸 ラーメン 1位 とみ田」「最近の作業BGM 2位 この曲」みたいに、今の自分の好きを雑に残して、あとでテーマごとに見返せるアプリです。

価値の中心は「全部を整理する」ではなく、「3つに絞ることで、自分の好みが見える」ことです。

## タグライン案

- 好きなものを、3つだけ残す。
- 今日の偏愛を、Top3で記録する。
- 日記より軽く、ブックマークより自分らしく。
- 迷ったら、1位から3位まで。
- あなたの「好き」が、あとから見える。

## 毎日使いたくなる入力体験

### 基本方針

入力は「正しく管理する」より「迷わず残せる」ことを優先する。

ユーザーは毎日、`タグ / 場所 / 順位 / 店舗名 / メモ` の構造化フォームに入れて保存する。保存内容は `/api/items` 経由でDBに反映され、タグごとのTop3としてすぐ見返せる。

```txt
タグ: ラーメン / 場所: 松戸 / 順位: 1位 / 店舗名: とみ田 / メモ: 濃厚つけ麺
タグ: 作業BGM / 場所: 自宅 / 順位: 2位 / 店舗名: この曲 / メモ: 集中できる
タグ: カフェラテ / 場所: 柏の葉キャンパス / 順位: 1位 / 店舗名: Solito MAGO / メモ: また行きたい
```

### 気持ちよく続くポイント

- 構造化フォームだけで完結する
- タグ・場所・順位・店舗名・メモをあとから整理できる
- 1位だけでも保存できる
- 同じテーマで順位が重なったら自動で整う
- 保存後に「今のTop3」がすぐ見える
- 入力例が毎回少し変わり、何を入れればいいか迷わない

### 日替わりお題の例

- 買ってよかったもの Top3

- 人にすすめたいもの Top3

## オンボーディング文言

### 初回表示案

好きなものを、3つだけ残しましょう。

店、曲、場所、買ってよかったもの、また行きたいところ。  
`タグ / 場所 / 順位 / 店舗名 / メモ` をフォームに入れると、`/api/items` 経由でテーマごとのTop3として保存できます。

きれいに整理しなくて大丈夫。  
あとで見返したとき、今のあなたの「好き」がちゃんと残っています。

### 入力欄の補助文言

```txt
例: タグ=ラーメン / 場所=松戸 / 順位=1位 / 店舗名=とみ田 / メモ=濃厚つけ麺
```

または

```txt
タグ / 場所 / 順位 / 店舗名 / メモの構造化フォームで `/api/items` に保存します
```

### 空状態の文言

まだTop3がありません。

まずは「今日よかったもの」を1つだけ入れてみましょう。  
1位だけでも大丈夫です。

### 保存後の小さなフィードバック

- 保存しました。今のあなたの1位です。
- Top3に入りました。あとで見返すのが少し楽しみです。
- 同じテーマの順位を自動で整えました。
- これは殿堂入り候補かもしれません。

top3-favorites-app は、日々の「好き」をTop3形式で保存するMVPアプリです。
