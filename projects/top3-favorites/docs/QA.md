# top3-favorites 手動QA観点（MVP）

対象観点: 入力パース / タグ絞り込み / Google Mapsリンク / localStorage / 編集/削除 / JSON import-export安全性

## テストケース（11件）

1. **正常入力（メモあり）**
   - 手順: `松戸 ラーメン / 1位 / とみ田 / 濃厚つけ麺` を追加
   - 期待: 1件追加、`1位: とみ田` 表示、タグ `#松戸 #ラーメン`、メモ表示

2. **正常入力（メモ省略）**
   - 手順: `渋谷 カフェ / 2位 / 茶亭` を追加
   - 期待: 追加成功、メモ欄は `（メモなし）`

3. **入力パース（順位ゆらぎ）**
   - 手順: `池袋 寿司 / 第3位 / すし屋 / うまい` を追加
   - 期待: 順位が `3位` として保存される（1〜3の数字抽出）

4. **入力パース（不正フォーマット）**
   - 手順: `タグだけ / 1位` を追加
   - 期待: 追加されずエラー表示（形式不正）

5. **タグ正規化（#除去）**
   - 手順: `#新宿 #焼肉 / 1位 / 店A /` を追加
   - 期待: タグが `新宿`,`焼肉` として保持され、表示は `#新宿 #焼肉`

6. **絞り込み（テキスト検索）**
   - 手順: 検索欄に `とみ田` / `濃厚` / `松戸` を順に入力
   - 期待: 店名・メモ・タグのいずれでも対象のみ表示（部分一致）

7. **絞り込み（タグチップ）**
   - 手順: `#松戸` チップ押下 → `クリア` 押下
   - 期待: 押下時は該当のみ表示、クリアで全件表示に戻る

8. **Google Mapsリンク**
   - 手順: 任意アイテムの `Maps` クリック
   - 期待: 新規タブで `https://www.google.com/maps/search/?api=1&query=...` が開き、店名+タグがクエリに含まれる

9. **localStorage永続化**
   - 手順: 追加後にページ再読み込み
   - 期待: データが保持される（`top3-favorites-items` から復元）

10. **編集/削除**
    - 手順: 1件を編集（名前・順位変更）して保存 → 別件を削除
    - 期待: 編集内容が即反映、削除件は一覧から消える（再読み込み後も反映）

11. **JSONインポート fail-closed**
    - 手順: (a) 配列以外JSON、(b) 不正要素を含む配列JSON を順にインポート
    - 期待: いずれも反映されずエラー表示、既存データは保持される
