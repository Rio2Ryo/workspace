# top3-favorites 手動QA観点（現行UI）

対象観点: 構造化フォーム入力 / タグ絞り込み / Google Mapsリンク / `/api/items` 永続化 / 編集・削除 / JSON import-export安全性

## テストケース（11件）

1. **正常入力（メモあり）**
   - 手順: 構造化フォームに `タグ: ラーメン`, `場所: 松戸`, `順位: 1`, `店舗名: とみ田`, `メモ: 濃厚つけ麺` を入れて保存
   - 期待: 1件追加、`1位: とみ田` 表示、タグ `#ラーメン`、場所とメモ表示

2. **正常入力（メモ省略）**
   - 手順: `タグ: カフェ`, `場所: 渋谷`, `順位: 2`, `店舗名: 茶亭`, `メモ: 空` を保存
   - 期待: 追加成功、メモ欄は `（メモなし）`

3. **順位選択**
   - 手順: 順位ボタンまたは順位選択で `3位` を指定して保存
   - 期待: 順位が `3位` として保存される

4. **必須入力バリデーション**
   - 手順: タグまたは店舗名を空にして保存
   - 期待: 追加されず、`タグと店舗名は必須です。` が表示される

5. **タグ正規化（#除去）**
   - 手順: タグ欄に `#新宿 #焼肉` 相当の値を入れて保存
   - 期待: 表示は `#新宿 焼肉` ではなく、現行のタグ正規化ルールに従った単一タグとして扱われる

6. **絞り込み（テキスト検索）**
   - 手順: 検索欄に `とみ田` / `濃厚` / `松戸` を順に入力
   - 期待: 店名・メモ・場所・タグのいずれでも対象のみ表示（部分一致）

7. **絞り込み（タグチップ）**
   - 手順: `#ラーメン` チップ押下 → `クリア` 押下
   - 期待: 押下時は該当のみ表示、クリアで全件表示に戻る

8. **Google Mapsリンク**
   - 手順: 任意アイテムの `Maps` クリック
   - 期待: 新規タブで `https://www.google.com/maps/search/?api=1&query=...` が開き、店名+場所+タグがクエリに含まれる

9. **`/api/items` 永続化**
   - 手順: 追加後にページ再読み込み
   - 期待: `/api/items` から取得したデータが保持される

10. **編集/削除**
    - 手順: 1件を編集（店舗名・順位変更）して保存 → 別件を削除
    - 期待: 編集内容が即反映、削除件は一覧から消える（再読み込み後も反映）

11. **JSONインポート fail-closed**
    - 手順: (a) 配列以外JSON、(b) 不正要素を含む配列JSON を順にインポート
    - 期待: いずれも反映されずエラー表示、既存データは保持される
