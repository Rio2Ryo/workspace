# top3-favorites 手動確認チェックリスト

対象: `top3-goose` 実装完了後の受け入れ確認
前提: 実装変更はこのチェックでは行わない

---

## 0. 事前準備

- [ ] アプリを起動し、トップ画面が表示される
- [ ] ブラウザDevToolsで Console に致命的エラーがない
- [ ] 必要に応じて `localStorage(top3-favorites-items)` をクリアして初期状態から開始

---

## 1. 入力パース（基本）

- [ ] **正常入力（メモあり）**
  - 入力: `松戸 ラーメン / 1位 / とみ田 / 濃厚つけ麺`
  - 期待: 1件追加、`1位: とみ田`、タグ表示、メモ表示

- [ ] **正常入力（メモなし）**
  - 入力: `渋谷 カフェ / 2位 / 茶亭`
  - 期待: 追加され、メモ欄は `（メモなし）`

- [ ] **順位表記ゆらぎ**
  - 入力: `池袋 寿司 / 第3位 / すし屋 / うまい`
  - 期待: `3位` として保存

- [ ] **不正フォーマット**
  - 入力: `タグだけ / 1位`
  - 期待: 追加されずエラー表示

- [ ] **区切りなし自然文入力（重要）**
  - 入力例: `松戸で好きなラーメンはとみ田です濃厚つけ麺が好き`
  - 期待: 現行仕様で解釈不可なら、追加されずエラー表示（誤登録しない）

---

## 2. タグ絞り込み

- [ ] 検索欄で `店名/タグ/メモ` それぞれ部分一致検索が効く
- [ ] タグチップ押下で該当データのみ表示される
- [ ] `クリア` で全件表示に戻る

---

## 3. Google Mapsリンク

- [ ] 各アイテムの `Maps` を押すと新規タブでGoogle Maps検索が開く
- [ ] URLクエリに `店名 + タグ` が含まれる

---

## 4. DB保存 / サンプルデータ投入（重要）

> 現行実装は `/api/items` 経由で保存する。旧localStorage前提の確認は対象外。

### 4.1 JSONエクスポート/インポート（重要）

- [ ] **JSONエクスポート成功**
  - 手順: データが1件以上ある状態で `JSONエクスポート` を押す
  - 期待: `top3-favorites-*.json` がダウンロードされる

- [ ] **JSONインポート成功（正常データ）**
  - 手順: エクスポートしたJSONを `JSONインポート` で読み込む
  - 期待: 件数メッセージが表示され、一覧がJSON内容に置き換わる

- [ ] **JSONインポート失敗（配列以外）**
  - 手順: `{ "foo": 1 }` のようなJSONを読み込む
  - 期待: 反映されずエラー表示、既存データは保持される

- [ ] **JSONインポート失敗（不正要素混在）**
  - 手順: 配列内に `id` 欠損・`rank: 4`・`tags: []` など不正要素を1件混ぜる
  - 期待: 全体を反映しない（fail-closed）、既存データは保持される

- [ ] **JSONインポート失敗（壊れたJSON）**
  - 手順: パース不能な文字列を `.json` として読み込む
  - 期待: エラー表示、既存データは保持される


- [ ] **永続化確認**
  - 追加後に再読み込みしてデータが保持される

- [ ] **サンプルデータ投入（UI）**
  - 手順: `サンプルをDB保存` を押す
  - 期待: サンプル3件がDB保存され、再読み込み後も一覧へ反映される

- [ ] **API取得失敗耐性**
  - 手順: API停止またはネットワーク失敗を再現できる環境でトップ画面を開く
  - 期待: アプリがクラッシュせず、データ取得失敗メッセージが表示される

---

## 5. 編集/削除

- [ ] 編集ボタンで既存値が編集フォームに入る
- [ ] 編集保存で一覧表示が更新される
- [ ] 編集キャンセルで編集モードを抜ける
- [ ] 削除で対象のみ消える
- [ ] 削除後に再読み込みしても削除結果が維持される

---

## 6. 順位繰り下げ（重要）

> 本項目は「同一テーマ内でTop3運用の順位調整仕様」が実装されたタイミングで確認。

- [ ] 同一テーマで `1位/2位/3位` が存在する状態を作る
- [ ] 既存 `1位` に新しい `1位` 相当データを追加（または編集）
- [ ] 期待: 仕様どおりに順位繰り下げが発生する（例: 旧1位→2位、旧2位→3位）
- [ ] 期待: 4位相当の扱い（削除/保持/警告）が仕様どおりである
- [ ] 再読み込み後も順位結果が維持される

---

## 7. 判定

- [ ] すべてOKなら「受け入れ可」
- [ ] NGが1件でもあれば、再現手順・期待・実際を記録して差し戻し
