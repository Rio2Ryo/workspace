# 論文管理システム 要件定義

## プロジェクト概要

PDFをドロップするだけで、メタデータ抽出・ファイル名変更・Notion登録・要約生成まで
自動完結する論文管理ツール。

---

## 機能要件

### F1: PDF投入インターフェース
- `inbox/` ディレクトリへのファイルコピーで処理起動（CLI・後にウォッチャー対応）
- CLI: `python main.py <path_to_pdf>` でも動作

### F2: メタデータ自動抽出
対象フィールド:
| フィールド | Notion列名 | 備考 |
|-----------|-----------|------|
| 論文タイトル | タイトル | |
| 執筆者名 | 執筆者 | 複数名はカンマ区切り |
| 雑誌名/論文集名 | 雑誌名 | |
| 巻 | 巻 | 存在しない場合は空 |
| 号 | 号 | |
| 頁 | 頁 | 開始-終了（例: 45-67）|
| 発行年 | Year | 西暦4桁 |
| DOI / ISSN | DOI | あれば |

抽出手順:
1. PDFテキスト抽出（PyMuPDF）
2. Claude API でメタデータ構造化（JSON出力）
3. **CiNii と NDL で必ず照合・精査**
4. 不明フィールドは `"わからない"` を返す（補完しない）

### F3: ファイル名生成・リネーム
フォーマット:
```
執筆者名「論文名」論文集名X巻Y号Z頁（発行年）
```

ルール:
- 執筆者名: 引用符なし（複数名は「田中・鈴木」等）
- 巻: 数字のみ（「第」不要）、存在しない場合は省略
- 号: 数字のみ（「第」不要）
- 頁: 「頁」表記（「p」不可）
- 年: 西暦のみ（「年」不要、丸括弧内）
- 論文集名: 『』不要
- 改行禁止
- 不明フィールドがある場合はリネームせず警告出力

例:
```
田中太郎「特許制度の意義と限界」知的財産研究3巻2号45頁（2020）.pdf
鈴木花子「著作権と学術論文の公開」法学論叢128号123頁（2019）.pdf
```

### F4: Notion DB 登録
対象DB: `文献管理`
登録フィールド:
- タイトル（ファイル名形式の整形済み文字列）
- PDF（ファイル添付 または ローカルパス記録）
- Year
- 雑誌名
- 執筆者
- メモ（要約を自動挿入）
- タイプ（デフォルト: 論文）

### F5: 論文要約生成
- Claude API でPDF全文から3〜5行の日本語要約を生成
- Notion の「メモ」列に自動挿入

---

## 非機能要件

### セキュリティ
- APIキー・Notion Token は `.env` 管理、コードにハードコードしない
- `.env` は `.gitignore` に含める
- `.env.example` でスキーマ公開

### 拡張性（将来対応想定）
- キーワード検索: Notion DB にタグ列追加で対応
- 相互参照: DOI / 引用元フィールドで紐づけ
- ユーザーメモ統合: Notion のメモ列に追記形式

### 制約
- ローカル実行（外部公開なし）
- Python 3.10+
- API呼び出しは Claude (Anthropic) + CiNii REST + NDL デジタルコレクション API

---

## 外部API一覧

| サービス | 用途 | 認証 |
|---------|-----|-----|
| Anthropic Claude API | メタデータ抽出・要約 | APIキー |
| CiNii Research API | 論文メタデータ照合 | 不要（公開API）|
| NDL デジタルコレクション API | 論文メタデータ照合 | 不要（公開API）|
| Notion API | DB登録 | Integration Token |
