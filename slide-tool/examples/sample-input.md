# Slide Tool PoC

## 目的

- 文章や要件からスライド構成を作る
- PowerPointで編集できる資料にする
- 提案書、見積書、事業計画の叩き台を高速に作る

## 想定ユーザー

- Ryoさん
- 空、青、白、黒の各担当
- 提案資料や要件整理を短時間で作りたいメンバー

## 最小機能

- Markdown入力を読む
- スライド構成JSONを出す
- PPTXを生成する
- 外部APIなしで動く

## 技術方針

- Node.js
- pptxgenjs
- 編集可能テキストを優先
- polished版は将来SVG/PNG方式を追加する
