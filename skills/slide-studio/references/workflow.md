# Shiro Slide Studio Reference

Load this when planning a slide workflow or explaining tool selection.

## Standard Flow

Discord natural language -> requirement extraction -> outline JSON -> HTML/Artifact preview -> GPT Image 2 prompts -> editable PPTX -> revision loop -> delivery.

## Tool Selection

- Shiro Slide Studio: default local workflow for outline, preview, PPTX, prompts, verification.
- GPT Image 2: cover/key visual/diagram/icon generation. Prompt only unless paid API use is approved.
- Canva: brand polish, manual finishing, multi-format design adaptation. External upload/publish needs approval.
- Gamma: fast concept exploration and web-native drafts. Validate PPTX editability before delivery.
- Presenton: local/OSS comparison path for PPTX/PDF generation.
- Plus AI: PowerPoint/Google Slides-native AI editing path.
- Claude Design/Artifacts: reference model for conversational design and HTML/artifact-first iteration.

## Intake

Extract:

- topic
- audience
- decision to unlock
- desired slide count
- tone
- must include
- must avoid
- sources
- output formats
- external API/publication permission

Ask at most three questions only if the deck cannot be safely scoped.
