# 会社設立エージェント PoC計画

## 選定
第一対象: freee会社設立
法人形態: 株式会社

理由:
- 住所公開リスクを避けるため、代表取締役等住所非表示措置を検討できる株式会社で進める
- 設立後にfreee会計・人事労務API連携へ広げやすい
- 日本法人設立フローの実用性が高い
- 入力補助→会計初期設定まで一気通貫にしやすい

## PoCゴール
外部提出・支払い・電子署名を一切行わず、freee会社設立の入力補助と確認フローを検証する。

## スコープ

### やること
1. 設立ヒアリング項目の整理
2. 会社情報JSON/YAMLの生成
3. freee会社設立画面の確認
4. 下書き入力の補助
5. 入力内容のスクリーンショット保存
6. 提出直前で停止
7. Ryoさん確認用サマリー生成

### やらないこと
- 定款確定
- 電子署名
- 支払い
- 登記申請
- 外部送信
- freee上の最終送信

## 承認ゲート

| ゲート | 内容 | AI単独実行 |
|---|---|---|
| G1 | 入力ドラフト作成 | 可 |
| G2 | freee画面への下書き入力 | 可 |
| G3 | 内容確認サマリー作成 | 可 |
| G4 | 定款/登記内容の確定 | 不可 |
| G5 | 署名・支払い・提出 | 不可 |
